PiP Anywhere

Install the helper once, from the project folder:

./scripts/install-linux.sh

Then log out and back in (GNOME only loads new extensions at login).

Unzip pip-anywhere-windows.zip and double-click install.cmd.

No administrator rights needed. Then reopen this popup.

This operating system is not supported yet. PiP Anywhere works on Windows and on Linux with GNOME.
